# Amanda Freitas — Agendamento e Controle de Caixa

App (PWA) para registrar atendimentos e custos e acompanhar recebido, gastos e lucro por dia, semana e mês.

- Funciona offline e pode ser instalado na tela inicial do celular.
- Os dados ficam salvos **apenas no celular** (localStorage). Nada é enviado para servidor.
- Use **Fazer backup** com frequência e guarde o arquivo `.json`. **Restaurar backup** recupera os dados em outro aparelho.

## Instalar
- **Android (Chrome):** abra o link → toque em **Instalar** (ou menu ⋮ → *Adicionar à tela inicial* / *Instalar app*).
- **iPhone (Safari):** abra o link → **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar
Edite os arquivos e aumente `VERSAO` em `sw.js`.
